## Research & Publications

### [<code>ICCE-TW 2026</code>](https://arxiv.org/abs/2605.09554)&nbsp; Towards Compact Sign Language Translation: Frame Rate and Model Size Trade-offs
**First author.** Studies how input frame rate and model size trade off in gloss-free sign language translation from pose sequences. Reaches competitive results with a 77M-parameter T5-small decoder at reduced frame rates.

### [<code>ICCE-TW 2026</code>](https://www.researchgate.net/publication/404900026_STRLite_Lightweight_Masked_Autoencoders_for_Adaptable_Scene_Text_Recognition)&nbsp; [STRLite: Lightweight Masked Autoencoders for Adaptable Scene Text Recognition](https://github.com/balaboom123/STRLite)
**Co-first author.** A 6M-parameter ViT-Tiny scene text recognizer trained with MAE pretraining and autoregressive fine-tuning. Reaches 93.8% on the six common STR benchmarks and 81.0% on Union14M.

### [<code>arXiv 2026  </code>](https://arxiv.org/abs/2604.20357)&nbsp; [SignDATA: Data Pipeline for Sign Language Translation](https://github.com/balaboom123/signdata-slt)
**First author.** A config-driven pipeline that preprocesses 12 sign language datasets into pose landmarks or video clips using MediaPipe, MMPose, and YOLO. Ships WebDataset shards ready for training and has passed 100 stars on GitHub.

### [<code>ICETA 2024  </code>](https://digital-library.theiet.org/doi/abs/10.1049/icp.2024.4141)&nbsp; [Two-step Authentication: Multi-biometric System Using Voice and Facial Recognition](https://github.com/NCUE-EE-AIAL/Two-step-Authentication-Multi-biometric-System)
**First author.** A real-time two-step authentication system that combines VGG-16 face recognition with ResCNN voice verification. Published in the IET ICETA 2024 proceedings.
